# {{APP_NAME}} 실행 안내 (수료 후 사용 패키지)

이 폴더는 ALEPH 과정에서 만든 보안 Agent 프로젝트를 워크벤치와 ALEPH 포털 없이 실행할 수 있도록 복사한 패키지입니다.

- 만든 시각: {{CREATED_AT}}
- 시작 틀 버전: {{STARTER_VERSION}}
- 포함한 파일: {{FILE_COUNT}}개(목록과 SHA-256 은 `PACKAGE_MANIFEST.json`)
- 앱 이름 {{APP_NAME}}은 이 안내와 목록에만 적었습니다. 앱 화면 제목과 코드는 바꾸지 않습니다. 새 독립 실행의 실제 앱 이름은 프로젝트 밖 개인 설정의 appName으로 지정합니다(`docs/PERSONAL_AI_SETUP.md`).

## 1. 준비할 것

- Windows PC와 `package.json`의 `engines.node`에 적힌 Node.js가 필요합니다(현재 수업 기준 24.19.0). `PACKAGE_MANIFEST.json`에는 원본의 요구 버전과 내보내기 도구를 실행한 실제 Node 버전이 함께 기록됩니다. 다른 버전의 실행 성공을 대신 증명하지 않습니다.
- 미연결 기본 실행과 예제 화면에는 인터넷과 외부 npm 패키지가 필요하지 않습니다. 실제 AI·SDP·XDR 서버 연결에는 해당 서비스와 네트워크가 따로 필요합니다. `npm install`은 실행하지 않아도 됩니다.

## 2. 실행하기

1. 파일 탐색기에서 이 폴더를 엽니다.
2. 주소 표시줄에 `powershell`을 입력하고 Enter를 누릅니다.
3. 아래 명령을 실행합니다.

```powershell
{{START_COMMAND}}
```

4. `http://127.0.0.1:5189` 가 표시되면 브라우저에서 그 주소를 엽니다.
5. 끝낼 때는 PowerShell 창에서 `Ctrl+C`를 누릅니다.

`tools\{{LAUNCHER}}`가 들어 있다면 아래 명령으로도 실행할 수 있습니다. 상세 조건은 해당 실행 도구 안내를 확인합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\{{LAUNCHER}}
```

직접 node로 실행할 때 포트가 겹치면 `$env:ON_PORT=5190`을 먼저 실행합니다. PowerShell 실행 도구를 쓰는 경우에는 명령 끝에 `-Port 5190`을 붙입니다. 브라우저 주소도 `:5190`으로 엽니다.

## 3. 화면에 보이는 상태의 뜻

- **기본 실행은 "연결 없음"입니다.** 회사 접근 제어 서버나 XDR 서버에 연결하지 않았기 때문에 사용자·기기·기록 칸은 확인 불가로 보입니다. 오류가 아니라 정상입니다.
- **예제 화면**을 보려면 `{{DEMO_COMMAND}}`로 실행합니다. 예제 자료는 화면 모양을 확인하는 용도이며, 실제 연결이나 실제 보안 판정이 아닙니다.
- 과정에서 아직 구현하지 않은 단계의 기능은 화면에 없거나 "준비 중"으로 보일 수 있습니다. 이 패키지를 완성된 보안 제품으로 소개하지 않습니다.

## 4. 수료 후 달라지는 것

- **수업용 AI 연결은 수료 후 쓸 수 없다고 보고 준비합니다.** 앱 안의 AI 설명 기능은 앱 권한이 발급돼야 동작하며, 기본 상태에서는 실제 AI 호출을 막아 둡니다. 학원 계정과 AI 사용 권한이 계속 유지된다고 약속하지 않습니다.
- 회사·개인 서버에 연결하려면 접근 제어 서버, 인증서, AI 키 같은 별도 준비가 필요합니다. 주소와 키만 바꾸면 바로 된다는 뜻이 아닙니다. 자세한 범위는 `docs/AFTER_COURSE_GUIDE.md`를 봅니다.
- AI 키·비밀번호·토큰은 이 폴더, Git 저장소, 압축 파일, 대화창에 넣지 않습니다.
- 개인 AI 실행 경로가 함께 제공된 경우 `docs/PERSONAL_AI_SETUP.md`를 따릅니다. 개인 AI는 공식 과제 판정과 별개이며 실제 공급사 유료 호출은 이번 패키지 검사에서 실행하지 않았습니다.

## 5. 파일이 그대로인지 확인하기

내보낸 뒤 파일이 바뀌거나 빠지지 않았는지 확인하려면, 이 폴더에서 아래 명령을 실행합니다. 내보내기 도구(`tools/export-student-package.mjs`)는 이 패키지에 함께 들어 있습니다.

```powershell
node tools/export-student-package.mjs --verify .
```

내 코드를 고친 뒤에는 목록과 달라지는 것이 정상입니다. 고친 버전을 새로 보관하려면 원래 과제 폴더에서 다시 내보냅니다.

## 6. 다시 내보내기

과정에서 쓰던 프로젝트를 더 고친 뒤 새로 보관하려면, 이 폴더의 PowerShell에서 아래처럼 원래 on-client 폴더를 `--source`로 지정해 실행합니다. `--out`에는 아직 없는 새 폴더 이름을 적습니다. 이미 있는 폴더는 덮어쓰지 않습니다.

```powershell
node tools/export-student-package.mjs --source "원래 on-client 폴더 경로" --out ..\keshev-package-2
```

이 패키지 폴더 자체를 `--source`로 지정해 복사본을 하나 더 만들 수도 있습니다.

목록의 SHA-256은 파일 일치 확인용이며 배포 주체를 인증하는 서명이 아닙니다. 알려진 비밀 파일·저장소·DB·로그와 내부 판정 소스는 제외하지만 모든 바이너리나 임의 이름의 비밀을 완전히 찾지는 못합니다. 공유하기 전 포함 파일과 제외 목록을 직접 확인합니다. 실패한 부분 폴더는 자동 삭제하지 않습니다. 표시된 경로를 확인하고 담당자에게 문의합니다.
