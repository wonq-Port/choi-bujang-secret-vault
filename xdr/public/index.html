보호된 자료실 & 탈환 작전실

제공된 ALEPH SDP 엔진과 학생 판정·탐지·회수·복구·서명 검증의 실제 API 결과를 읽는 탈환 작전실입니다. 화면 문구만으로 통과를 가정하지 않으며, 가상 메모 본문은 작전실에 표시하지 않습니다.

오프라인 안내: 현재 네트워크에 연결되어 있지 않습니다. 보호 자료나 기기 키·토큰은 오프라인에 보관하지 않으므로, 온라인 연결 후 서버 검증을 거쳐야 합니다.

탈환 작전실 (실제 API 응답 요약 · 메모 본문 비표시)

• 출처 구분: 신원·기기·경로 기본 계약은 ALEPH SDP 엔진을 사용하며, 판정 규칙(src/decider.mjs)·탐지 규칙(src/detect.mjs)·회수·단건 복구·요청 서명은 학생이 구현했습니다.
• 아래 수치는 서버(GET /api/ops)의 가린 감사 기록과 1:1로 일치하며, 실행하지 않은 항목은 미실행으로 구분합니다.

1. 판정기 규칙 (Decider)

조회 전 (미실행)

2. 탐지 사건 (Detection)

조회 전 (미실행)

조회 전 (미실행)

조회 전 (미실행)
가린 서버 기록 대조: 아직 조회되지 않음 (미실행 · 메모 본문 미포함)

1~11단계 정상·금지 요청 실측 결과 표 (총 41종 중 미실행 항목 구분)

단계 / 구분 정상·금지 요청 항목 기대 결과 실제 API 결과 요청 ID (requestId) 확인 시각 (checkedAt)
기기 승인 상태 미승인 · 승인 전 보호 자료 비공개

• 주의: 홈 화면이나 데스크톱에 웹앱을 설치했다는 표시(manifest)만으로 기기 확인이 끝난 것으로 인정하지 않습니다.
• 오프라인 및 보안 안내: 기기 개인키와 인증 토큰은 브라우저 저장소에 넣지 않고 메모리에서만 유지합니다.
